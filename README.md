# Що подивитися?

Трекер фільмів і серіалів. Каталог показує всі записи, шукає за частиною назви та фільтрує за жанром і статусом. Показники над каталогом охоплюють усю колекцію. Середня оцінка враховує тільки оцінені записи.

## Локальний запуск у Windows

У корені розпакованого проєкту виконайте у PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Відкрийте локальну адресу, яку виведе Streamlit. У бічному меню доступні три сторінки. Каталог відкривається за головною адресою, керування записами — за шляхом `/manage`, сторінка автора — за шляхом `/author`.

## Структура

- `app.py` — каталог, керування записами та сторінка автора.
- `db.py` — схема, початкові дані, транзакції, перевірки та параметризовані SQL-запити.
- `genres(id PK, name UNIQUE)` — довідник жанрів.
- `titles(id PK, name, year, kind, genre_id FK, status, rating)` — записи каталогу. Один жанр може належати багатьом записам. Видалення використаного жанру обмежене зовнішнім ключем.
- `.streamlit/config.toml` — кольори інтерфейсу.

Перший запуск створює поруч із програмою `watchlist.sqlite3`, п'ять жанрів і шість демонстраційних записів. Наступні запуски зберігають зміни, зокрема порожній каталог після видалення всіх записів. Для іншого шляху можна задати змінну середовища `WATCHLIST_DB`. Навчальний застосунок має спільну базу для всіх сеансів. Оцінки демонстраційні.
